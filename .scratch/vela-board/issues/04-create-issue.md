# 04 — 创建 Issue 并在 Board 上展示

**What to build:** Operator 能新建一个 Issue，填写标题、描述、Workspace 与优先级，它作为一张卡片出现在 Backlog Lane，并且**重启 dsh 之后仍在**。这是 Vela 第一个真正可用的里程碑——在此之前没有任何东西值得演示。

**Blocked by:** 01 — 插件骨架与从零安装验证；03 — Board 面板与导航入口
