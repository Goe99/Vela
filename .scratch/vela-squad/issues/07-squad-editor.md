# 07 — Squad 编辑器界面

**What to build:** 从左侧「Squads」进去是一个全屏页，列出所有小队。能新建一支队：写队长的职责说明，加队员——每个队员填名字、职责说明、勾选它能用哪几类工具、选执行后端。存盘后这支队立刻可用。

按 ADR-0017：沙箱档位是**整支队**的一个选择，工具白名单是**每个队员**各自的选择。界面上这两者层级不同，不能摆成同一排。

**Blocked by:** 06 — Squad 落成 preset 文件；03 — 左侧导航（提供入口）
