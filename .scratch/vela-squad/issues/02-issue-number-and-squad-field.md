# 02 — Issue 形状扩容：任务编号与小队字段

**What to build:** 每张卡有一个稳定、可口头引用的编号（例如 `V-12`），在卡片和详情里都看得见；同时为「这张卡派给哪支小队」预留字段。已有的存档自动补齐，不需要 Operator 做任何事。
