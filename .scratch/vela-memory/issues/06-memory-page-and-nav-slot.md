### 四种状态必须分开说

这一页最容易做错的地方不是列表，是**空列表的四种成因**：还没拉到、拉取失败、没配 `memoryPath`、真的一篇都没有。四者混成一个空页会让 Operator 以为「记忆功能不好使」，而实情可能是他没开。四条各自一个渲染测试锁住。

### 一处安全修补

删除接口收的是一条相对路径（`runs/<工作区>/12-r1.md`），而它最终来自 HTTP 请求。一个 `../../` 就能把它变成**任意文件删除**。因此在记忆库那一层拒绝绝对路径与带 `..` 的路径（报错而不是静默忽略），并用一条测试锁住。防御放在拥有根目录的那一层，而不是路由层——日后多一个调用方也自动受保护。

### 路径为何进请求体

复盘路径带着斜杠，塞进 URL 路径段要编码两次（`%252F`），而那是一类经典的目录穿越源头。因此删除走 `POST /memory/remove` 加请求体，而不是 `DELETE /memory/:path`。
