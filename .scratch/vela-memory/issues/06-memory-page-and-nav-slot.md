# 06 — 记忆页与导航第十三项

**What to build:** 左侧导航的「工作区」组里多一项「记忆」，点了进一个 Vela 自己画的页面：按 Workspace 列出全部复盘，每篇看得到标题、什么时候落的、信任等级、以及有没有过期；点开能在页面里读正文；能删，删了在更新历史里留一行。没配记忆库路径时页面明确说「没开启」，不是给一个看起来像"还没有记忆"的空列表。

这是 Vela 自己画的第四处界面，也是**打破十二项导航形状**的那一次破例（ADR-0024）。

**Blocked by:** 03 — 成功的执行落下一篇复盘

**Status:** ready-for-agent

- [ ] 导航多一项「记忆」，在「工作区」组、小队之后用量之前
- [ ] 锁归属表的那条契约测试跟着改（数量、键名清单），但**核心不变量不动**：每项都有明确归属、置灰两种原因分得开
- [ ] 页面按 Workspace 分组列出复盘，每篇显示信任等级与是否陈旧
- [ ] 点开能读正文，不必离开面板
- [ ] 能删除，删了在更新历史里留一行——不静默消失
- [ ] 没配路径时明确显示「没开启」，与「一篇都没有」在文案上分得开
- [ ] 一篇解析不了的文件显示成「这篇读不了」并给出原因，**不从列表里消失**
- [ ] 数据一律经现有的数据客户端取，不另开 fetch 通道
- [ ] 样式进现有的 `data-vela-*` 体系；**用到的 CSS 变量必须先定义再引用**
- [ ] 渲染测试覆盖：正常列表、没开启、读不了三种态
- [ ] 页面的所有长生命周期资源随插件卸载清理干净
