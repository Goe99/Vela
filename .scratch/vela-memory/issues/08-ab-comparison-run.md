# 08 — 对比实跑：开记忆与关记忆各五次

**What to build:** 拿真实数字回答「这套记忆到底有没有用」。同一批卡片跑两轮——记忆库配上、记忆库拿掉——比两件事：重复读同一个文件的次数有没有降，输入 token 有没有降。跑完出一份记录：每次执行的原始计数、样本数、以及怎么测的。这份记录是简历上那几个数字的出处，面试被追问「怎么测的」时有东西可指。

**这张票必须由人跑**：Gate 是人工验收环节，没有 Operator 按下接受，就没有人审过的复盘，也就没有可召回的东西。

**Blocked by:** 07 — 召回注入与可见性，外加指标埋点

**Status:** ready-for-human

- [ ] 靶子是 Vela 自己这个仓库（最熟，能判断 Agent 干得对不对）
- [ ] 准备 5 张同形态不同目标的卡（例如「给某个纯逻辑文件补测试」这类重复形态的活）——**不能用完全相同的任务**，第二次会因为活已经干完而失效
- [ ] 开记忆跑 5 次、关记忆跑 5 次，共 10 次执行；开关方式就是配不配 `memoryPath`，**不为实验加代码开关**（省得开关本身成为变量）
- [ ] 开记忆那轮，每次执行后正常走验收——不验收就没有可召回的复盘，实验会退化成两轮空跑
- [ ] 汇总时报告：重复读文件次数、输入 token、缓存读 token，三项分列
- [ ] **每个结论都带样本数**；某项没测出差异就写「没测出」，不写「没有差异」
- [ ] 原始计数留成一份记录文件，可回查
- [ ] 数字落地后回填简历里的三处待补；**做多少写多少**，跑不出差异就只写做了什么，不写效果
